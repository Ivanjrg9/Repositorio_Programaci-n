# Programación orientada a objetos en Java · 1º DAW

Ejercicios y prácticas de **programación orientada a objetos** de 1º de Desarrollo de Aplicaciones Web, escritos en **Java** como proyecto **Maven**.

## Contenido

El proyecto está en [`ObjetosProgramacion/`](ObjetosProgramacion) y trabaja estos temas:

- **Clases y objetos**: modelado de casos como una biblioteca (`Biblioteca/`), un chalet (`Chalet/`) o un autobús.
- **Herencia y polimorfismo**: jerarquía de empleados (`Ejercicio2/`).
- **Interfaces**: dispositivos y control remoto (`EjercicioClaseInterfaces/`).
- **Colecciones**: listas, colas y operaciones con `ArrayList` (`Colecciones/`).
- **Pruebas** con JUnit 5 configuradas en el `pom.xml`.
- **Exámenes prácticos y repasos** de las unidades 5, 6 y 7: aplicaciones completas con varias clases que colaboran entre sí.

## Cómo abrirlo

Requiere un JDK. Abre la carpeta `ObjetosProgramacion` como proyecto Maven en IntelliJ IDEA y ejecuta la clase `...App` del ejercicio que quieras.
